# Logos das Quintas do Douro

40 logotipos, um por quinta, recolhidos dos sites oficiais. Para usar
em newsletters / emails HTML.

Duas versoes de cada logo:

| Pasta | O que e | Usar quando |
|---|---|---|
| `logos/<slug>.png` | Logo original, fundo transparente, margens recortadas | Tens controlo do fundo no teu template |
| `email/<slug>.png` | Tile 600&times;375 com fundo adaptativo (logos claros sobre bordeaux, escuros sobre creme) | Queres largar direto numa grelha e que se veja sempre |

## Exemplo num email HTML

```html
<img src="https://cdn.jsdelivr.net/gh/antoniomachadoo/quintas-douro-logos@main/email/quinta-do-vallado.png"
     alt="Quinta do Vallado" width="300" style="display:block;border:0">
```

- CDN (recomendado, rapido e com content-type certo): `https://cdn.jsdelivr.net/gh/antoniomachadoo/quintas-douro-logos@main/email/<slug>.png`
- Raw GitHub (alternativa): `https://raw.githubusercontent.com/antoniomachadoo/quintas-douro-logos/main/logos/<slug>.png`

`manifest.json` / `manifest.csv` tem a lista completa com URLs. `index.html` pre-visualiza tudo.
